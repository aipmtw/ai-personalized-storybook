# 小美的恐龍冒險 — AI 個人化語言繪本 MVP Demo

A working PWA demo of a personalized bilingual children's storybook.

## Features

- **Offline-capable** — works fully offline after first visit (Service Worker + cache-first strategy)
- **Installable** — "Add to Home Screen" prompt for a native app feel
- **LINE Login** — authentication gate via LINE OIDC (with demo bypass)
- **Bilingual** — 繁體中文 + English side by side
- **Touch-friendly** — swipe or tap to turn pages, smooth CSS animations

## Story

"小美的恐龍冒險" (Mei's Dinosaur Adventure) — a 10-page bilingual storybook for ages 4-6, about a girl who discovers a friendly dinosaur in her garden and goes on a sky-high adventure.
